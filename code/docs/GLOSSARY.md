# THUẬT NGỮ HỆ THỐNG (GLOSSARY)

## 1. Tác nhân (Actor)
- **Admin**: Quản trị viên tại Trụ sở chính (HQ).
- **Staff**: Nhân viên tại Chi nhánh (Branch).

## 2. Use Case (UC)
- **UC01**: Đăng nhập
- **UC02**: Quản lý tài khoản và phân quyền
- **UC03**: Quản lý chi nhánh
- **UC04**: Quản lý sản phẩm và danh mục
- **UC05**: Quản lý nhà cung cấp
- **UC06**: Quản lý bảng giá
- **UC07**: Xem báo cáo tổng hợp
- **UC08**: Quản lý khách hàng
- **UC09**: Tra cứu giá riêng theo khách hàng
- **UC10**: Lập hóa đơn bán hàng
- **UC11**: Lập phiếu trả hàng
- **UC12**: Lập phiếu nhập kho
- **UC13**: Tra cứu tồn kho
- **UC14**: Theo dõi công nợ

## 3. Chứng từ
- **Hóa đơn** (Sales Invoice)
- **Phiếu trả** (Goods Return)
- **Phiếu nhập** (Inbound Receipt)

## 4. Trạng thái
- **DRAFT**: Nháp
- **CONFIRMED**: Đã xác nhận
- **CANCELLED**: Đã hủy

## 5. Module
- **Kho hàng** (Inventory)
- **Công nợ** (Receivable Debt / CRM)
- **Khách hàng** (Customer / CRM)
