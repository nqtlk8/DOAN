# Front-End Architecture

Thư mục này chứa tài liệu thiết kế kiến trúc dành riêng cho giao diện React/Vite. AI Kỹ sư Frontend sẽ sử dụng các tài liệu này làm bản vẽ thi công.

### Cấu trúc thư mục:
- `components/`: Tài liệu đặc tả cấu trúc của các Component tái sử dụng (ví dụ: Button, Table, FilterDate).
- `state-management/`: Tài liệu định nghĩa luồng dữ liệu (Data flow) và cách quản lý Global State (Redux, Zustand, hoặc Context API).
- `routing.md` (Tùy chọn): Bản đồ các đường dẫn (URL) của ứng dụng.
