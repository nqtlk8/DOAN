# Business Documentation

Thư mục này là trái tim của dự án, nơi lưu trữ toàn bộ các yêu cầu nghiệp vụ thực tế từ người dùng. 
Bất kỳ khi nào có một yêu cầu tính năng mới, bạn hãy thêm vào đây trước tiên. AI Architect sẽ đọc các file này để chuyển đổi thành ngôn ngữ kỹ thuật.

### Cấu trúc thư mục:
- `workflows/`: Lưu trữ mô tả các quy trình nghiệp vụ (ví dụ: Quy trình tạo đơn báo giá -> chốt đơn -> xuất kho).
- `requirements.md` (Tùy chọn): File tổng hợp các chức năng hệ thống.
